# Датасеты знаний: сценарий → база → плагин

Сценарии `knowledge.*` только забирают данные: `await ctx.dataset_record(имя, ключ, max_age, args)`
(`docs/contracts/scripts-sdk.md`). Данные готовят плагины (`docs/contracts/extensions.md`,
`datasets/*.py`, `DATASETS = {"имя": async fn(key, args)}`). Плагина нет — `SDKError` → помощник
`ctx.no_data_source()` (090): «Простой» — «Для этого нет источника данных.», «Модель/Агент» — отказ,
фраза уходит модели. Плагин есть — сценарий отвечает по шаблону во всех режимах; запись устарела
(`record["stale"]`) — сценарий говорит, на какое время данные.

## Домены

| Домен (датасет) | Ключ | args | Значение | Сценарий говорит |
|---|---|---|---|---|
| `facts` | вопрос (нормализованный) | — | `{"answer": str, "source": str?}` | ответ (+источник) |
| `translate` | `"<текст>"`, args `{"lang": str}` | — | `{"text": str, "lang": str}` | «<text> (язык)» |
| `prices` | `"currency:USD"` / `"crypto:BTC"` / `"stock:<тикер>"` / `"good:<товар>"` | — | `{"value": float, "unit": str, "updated": iso}` | «<unit>: <value>» |
| `places` | `"<что>"` | `{lat, lon}` из профиля | `{"items": [{"name", "address", "distance_m"}]}` | список до 3 |
| `route` | `"<куда>"` | `{from}` | `{"minutes": int, "km": float, "mode": str}` | «≈N мин (M км)» |
| `traffic` | `"<город>"` или `""` | — | `{"score": int, "text": str?}` | «Пробки: N» |
| `news` | `"top"` / `"<тема>"` | — | `{"items": [{"title", "source"}]}` | список до 3 |
| `tv` | `"<канал>"` / `"now"` | — | `{"items": [{"channel", "title", "start"}]}` | список |
| `recipes` | `"<блюдо>"` | — | `{"title", "ingredients": [str], "steps": [str]}` | кратко |

Каждый датасет независим: расширение может закрывать любые домены, не все.

## Привязка домена к плагину расширения — БЛОКЕР (090/081, 2026-11-03)

Расширения регистрируют датасеты только в своём пространстве имён (`<ext-id>.news` — префикс
обязателен, `runtime.py`), а сценарии знаний запрашивают общее имя (`news`). Механизма
«домен → датасет расширения» нет. Варианты (решает владелец):

1. **Настройка-привязка**: `settings.data_sources = {"news": "myext.news"}` — явная привязка
   домена к датасету в UI «Дополнительно»; сценарий читает её перед `dataset_record`.
2. **Автопоиск по суффиксу**: нет плагина `news` — берётся единственный включённый `*.news`;
   если несколько — по настройке из п. 1 или по алфавиту с warning.
3. **Ослабить префиксное правило**: разрешить расширениям системные имена (риск коллизий —
   сейчас именно они запрещены).

Сценарии знаний написаны под общие имена (заработают со встроенным плагином или после решения).
БЛОКЕР: код привязки не писан до выбора варианта.

## Открытые источники для будущих плагинов (без ключей)

- Курсы ЦБ РФ: `https://www.cbr-xml-daily.ru/daily_json.js` (датасет `prices`).
- Новости: RSS-ленты любых изданий (датасет `news`).
- Справочные факты: статьи Википедии (датасет `facts`).
- ТВ-программа: открытые JSON-источники программ (датасет `tv`).

С ключами (перевод, места, маршруты): Яндекс.Переводчик, Яндекс.Карты/Геосаджест — перечисление
не задаёт выбор, плагин-провайдер согласуется отдельно.

# Видео (каталог ссылок) — встроенный поставщик видео эмулятора

Поставляется с эмулятором (`server_emulator/plugins/video-links/`, id `builtin.video-links`):
виден во вкладке «Расширения» как «Встроенные», включён по умолчанию, удалить и
обновить отдельно нельзя. В «Поставщиках данных → Видео» — выбрать его или внешнего
поставщика (расширение с папкой `video/*.py`).

## Что делает

Без сети: выдача и запуск — из каталога ссылок, который правится в настройках плагина
(«Расширения → Видео (каталог ссылок) → Каталог видео (JSON)») без правки кода:

```json
[
 {"title": "Название", "embed": "https://…/video_ext.php?…", "url": "https://…",
  "genre": "комедия", "host": "vk.com", "player": "vk",
  "duration": 7149, "year": 2007, "preview": "https://…"}
]
```

- `title`, `embed` — обязательны; остальные поля необязательны (`host`/`player`
  определяются из адреса `embed` сами).
- Ссылки открывает плеер самой колонки — `play_web_video_directive`; карточки выдачи
  — `open_search`, выбор по номеру голосом («один», «номер два»).

Формат записи и смысл каждого поля описан в докстринге `video/video_links.py`.

# Источник совместимости

HTTP-контракты Quasar, оболочка WS Push и имена директив громкости/Bluetooth исследованы по [v3rt3p/quasar-server](https://github.com/v3rt3p/quasar-server), commit `d5f1a0c2f0b777f152cc5a3ffa3f8ae68e626c04`.

В package.json upstream указаны автор `radioegor146` и лицензия `MIT`; отдельного LICENSE в этом снимке нет. Здесь написан собственный Python-адаптер по изученным протокольным контрактам. Исходные TypeScript-файлы и зависимости upstream в пакет не скопированы. Локальный исследовательский клон находится в игнорируемой artifacts/quasar-server.

Адаптация: список устройств фильтруется по владельцу; конфиг берётся из состояния конкретного SN; токены локальные и привязаны к устройству/владельцу. Не перенесены глобальный список устройств, фиктивные подписки по умолчанию, внешняя телеметрия и ошибочный ответ 500 как реализация push_subscribe.

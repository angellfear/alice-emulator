Сценарии без ИИ

Простые команды (время, таймеры, будильники, свет, громкость, приложения) выполняются сценариями без обращения к модели; если сценария нет — отвечает ИИ.

Как описать сценарийОпределение — один файл на сценарий (state/scenarios): имя и описание ru/en, триггеры-паттерны; JSON — простой ответ, py-скрипт — логика.

Дерево: раздел → подраздел (_group пакета) → сценарии. ▸/▾ или клик по названию — свернуть/развернуть; галочка узла включает/выключает всё внутри.

Инструменты устройства и MCP

Схема инструмента передаётся модели только при enabled=true. Предложение модели не выполняется автоматически.

name, description, inputSchema, server_id, enabled. Заготовки из трафика требуют привязки к реальному исполнителю.

Расширения

Расширения добавляют сценарии, эндпоинты, конфиги Quasar, режимы «Интеллекта» и пакеты голосового стека.

Источники и безопасностьИсточник — каталог (JSON-индекс), GitHub-репозиторий, zip-ссылка или локальная папка. Расширения с кодом (классы «код» и «установка») исполняются в процессе сервера без песочницы: устанавливайте только то, чему доверяете.

Проверка цепочки

Проверяйте каждого провайдера отдельно или передайте запись → распознавание → модель → озвучка. Настройки нужно предварительно сохранить.

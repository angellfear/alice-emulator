# Яндекс Музыка — встроенный поставщик музыки эмулятора

Поставляется с эмулятором (`server_emulator/plugins/yandex-music/`,
id `builtin.yandex-music`): виден во вкладке «Расширения» как «Встроенные», включён
по умолчанию, удалить и обновить отдельно нельзя. Внешнее расширение Яндекс.Музыки
(если установлено) живёт рядом — в «Поставщиках данных» это два разных поставщика;
токен и ключ меты протокола определяются признаком сервиса
(`PROVIDER["service"] = "yandex-music"`), поэтому получают его оба.

## Что играет

Полные треки mp3 без DRM: прямые ссылки `storage.yandex.net` из
`api.music.yandex.net/tracks/<id>/download-info` (схема ссылки `url + "3/" + sign`).
Список вариантов — один запрос, XML со ссылкой запрашивается только у выбранного (лучший mp3
без превью): ответ на «включи музыку» — поиск, список, ссылка и конечный адрес, четыре запроса.
Если Яндекс сменит схему, ответ на «включи музыку» это покажет (честная ошибка в
речи, директив плеера не будет).

## Авторизация

Токен не вводится: эмулятор захватывает OAuth-токен аккаунта из реальных обращений
колонки к Яндексу (HTTP-заголовок `Authorization: OAuth …` и `X-UPRX-OAUTH-TOKEN`
в WS-handshake) и хранит в БД состояния (meta `yandex_oauth`). Чтобы заработало,
достаточно сказать колонке любую фразу. Статус захвата — во вкладке
«Поставщики данных → Музыка» (сам токен не показывается). Настройка — язык/регион
(`market`, по умолчанию `ru`).

## Фразы

| Фраза | Ответ |
|---|---|
| «включи музыку <название/исполнитель>» | поиск по Web API, играет первый трек |
| «включи музыку» | плейлист по умолчанию (настройка `default_playlist`: «Мне нравится» — по умолчанию, «Моя волна» или название своего плейлиста); плейлиста нет — «Что включить?» |
| «дальше» / «назад» | соседний трек очереди в порядке списка (ссылка добирается при переходе) |
| «включи сказку/подкаст/аудиокнигу …» | тот же поиск type=track |

## Ограничения

Лайк/дизлайк голосом не поддержан (`rate` → None). Очередь — первые 30 треков списка в
порядке плейлиста/выдачи (память плагина по SN колонки + хранилище сценария): переживает
«включи музыку» → «дальше» (разные запросы) и рестарт сервера; ссылки потока берутся у
ближайших треков заранее, у остальных — при переходе.

## Проверка

`python -m pytest tests/test_music_yandex.py -q` (из корня эмулятора): тесты
встроенного плагина на подменном HTTP — настоящий Яндекс из автотестов не вызывается.

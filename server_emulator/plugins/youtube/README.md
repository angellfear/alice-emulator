# YouTube — встроенный поставщик видео эмулятора

Поставляется с эмулятором (`server_emulator/plugins/youtube/`, id `builtin.youtube`),
включён по умолчанию. Свои фразы («найди на ютубе …») ведут к нему независимо от
выбранного в «Поставщиках данных → Видео».

## Что делает

- «найди на ютубе смешарики», «ютуб смешарики», «смешарики на ютубе» — поиск YouTube
  через [yt-dlp](https://github.com/yt-dlp/yt-dlp) (плоская выдача, ключ API не нужен),
  карточки `open_search` сценария `media.video`.
- Ролик запускается касанием карточки или голосом по номеру («один», «номер два») —
  плеер колонки открывает `youtube.com/embed/<id>?autoplay=1`.
- Превью — `i.ytimg.com/vi/<id>/hqdefault.jpg`.

## Настройки

«Роликов в выдаче» — от 1 до 20, по умолчанию 10.

## Проверка

`python -m pytest tests/test_video_scenario.py -q` (из корня эмулятора).

# Spotify — встроенный поставщик музыки эмулятора

Поставляется с эмулятором (`server_emulator/plugins/spotify/`, id `builtin.spotify`):
виден во вкладке «Расширения» как «Встроенные», включён по умолчанию, удалить и
обновить отдельно нельзя. Внешнее расширение Spotify (если установлено) живёт рядом
— в «Поставщиках данных» это два разных поставщика.

## Что играет

30-секундные превью mp3 (128 kbps, `p.scdn.co`) — единственный контент Spotify,
доступный вне их приложений; плеер колонки играет такие прямые ссылки штатным
`audio_play`. «Дальше/назад» — по очереди (до 30 треков) в памяти плагина (ключ — SN колонки,
кеш поиска — неделя).

## Ключи Web API

[developer.spotify.com](https://developer.spotify.com) → Dashboard → Create app:
`client_id` и `client_secret` — в настройки плагина («Расширения» или «Поставщики
данных → Музыка»); секрет можно хранить как `env:ИМЯ`. Без ключей работает только
ссылка на трек — точный трек берётся из открытой embed-страницы. Market — код
страны (по умолчанию `RU`).

## Фразы

| Фраза | Ответ |
|---|---|
| «включи музыку <название/исполнитель>» | поиск по Web API, играет первый трек с превью |
| «включи музыку» | плейлист по умолчанию (настройка `default_playlist`: ссылка или id публичного плейлиста, нужны ключи); не задан — случайный трек из кеша прошлых поисков; кеша нет — «Что включить?» |
| «включи музыку <ссылка на трек>» | точный трек: Web API по ключам или embed без ключей |
| «дальше» / «назад» | соседний трек очереди |
| «включи сказку/подкаст/аудиокнигу …» | тот же поиск type=track (превью только у музыки) |

## Сеть

Хосты в `permissions.network`: `accounts.spotify.com`, `api.spotify.com`,
`open.spotify.com`. Потоки (`p.scdn.co`) и обложки (`image-cdn.spotifycdn.com`)
колонка качает сама — эмулятор их не трогает.

## Проверка

`python -m pytest tests/test_music_spotify.py -q` (из корня эмулятора): модульные
тесты встроенного плагина на подменном HTTP — настоящий Spotify из автотестов не
вызывается.

# Данные знаний: сценарий → поставщик вида knowledge

Сценарий `knowledge.knowledge` (встроенный плагин `builtin.knowledge`, docs/contracts/scenarios.md)
только забирает данные: значение даёт поставщик вида `knowledge` с вкладки «Поставщики данных»
(`providers.py`). Поставщик объявляет себя сам (`contributes.providers`, модуль с `PROVIDER`),
потребитель объявляет обязательные функции: `providers.require("knowledge", ("record",), ("supports",))`:

- `async record(context, domain, key, args)` → значение домена (таблица ниже) |
  `{"value", "updated_at"}` (`updated_at` — Unix-секунды, когда данные получены) | None;
- `async supports(context, domain)` → bool — опционально: поставщик говорит, какие домены
  закрывает; функции нет — считаем, что закрывает все.

Поставщика нет, `supports`False, значение None или поставщик упал — `ctx.no_data_source()`:
«Простой» — «Для этого нет источника данных.», «Модель/Агент» — отказ, фраза уходит модели.
Поставщик есть — сценарий отвечает по шаблону во всех режимах; отметка `updated_at` старше
порога домена (`MAX_AGE` в сценарии) — сценарий говорит, на какое время данные.
Встроенного поставщика знаний нет: поставщик — расширение (выбор и спор видов —
docs/contracts/providers.md).

## Домены

| Домен | Ключ | args | Значение | Сценарий говорит |
|---|---|---|---|---|
| `facts` | вопрос (нормализованный) | — | `{"answer": str, "source": str?}` | ответ (+источник) |
| `translate` | `"<текст>"`, args `{"lang": str}` | — | `{"text": str, "lang": str}` | «<text> (язык)» |
| `prices` | `"currency:USD"` / `"crypto:BTC"` / `"stock:<тикер>"` / `"good:<товар>"` | — | `{"value": float, "unit": str, "updated": iso}` | «<unit>: <value>» |
| `places` | `"<что>"` | `{lat, lon}` из профиля | `{"items": [{"name", "address", "distance_m"}]}` | список до 3 |
| `route` | `"<куда>"` | `{from}` | `{"minutes": int, "km": float, "mode": str}` | «≈N мин (M км)» |
| `traffic` | `"<город>"` или `""` | — | `{"score": int, "text": str?}` | «Пробки: N» |
| `tv` | `"<канал>"` / `"now"` | — | `{"items": [{"channel", "title", "start"}]}` | список |
| `recipes` | `"<блюдо>"` | — | `{"title", "ingredients": [str], "steps": [str]}` | кратко |

Поставщик волен закрывать любые домены, не все — частное объявляется `supports`.

## Датасет-стор для знаний не используется

Раньше сценарий читал записи датасета (`ctx.dataset_record`, база `scenario_data`, кеш с возрастом).
Механизм «домен → датасет расширения» так и не появился (расширения регистрируют датасеты только
в своём пространстве имён), и для знаний он заменён поставщиком вида `knowledge`: кеш и свежесть
данных ведёт сам поставщик — как у новостей и музыки. `datasets/*.py` остаётся для остальных
потребителей (диспетчер погоды, `ha.lights` — docs/contracts/extensions.md).

## Открытые источники для будущих плагинов (без ключей)

- Курсы ЦБ РФ: `https://www.cbr-xml-daily.ru/daily_json.js` (домен `prices`).
- Справочные факты: статьи Википедии (домен `facts`).
- ТВ-программа: открытые JSON-источники программ (домен `tv`).

С ключами (перевод, места, маршруты): Яндекс.Переводчик, Яндекс.Карты/Геосаджест — перечисление
не задаёт выбор, плагин-поставщик согласуется отдельно.

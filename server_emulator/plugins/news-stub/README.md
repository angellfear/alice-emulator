# Новости (заглушка) — встроенный поставщик новостей эмулятора

Поставляется с эмулятором (`server_emulator/plugins/news-stub/`, id `builtin.news-stub`):
виден во вкладке «Расширения» как «Встроенные», включён по умолчанию, удалить и
обновить отдельно нельзя. В «Поставщиках данных → Новости» — выбрать его или внешнего
поставщика (расширение с папкой `news/*.py`).

## Что делает

Без сети: отдаёт 2–3 фиксированных заголовка, объявленных в самом плагине
(`news/news_stub.py`). Сценарий «что нового» произносит их репликой; директив
карточки нет — образца ответа настоящего сервера на «новости» в журнале нет, поэтому
пока только речь.

Заглушка — место-holder: заголовки правятся прямо в файле плагина или она
заменяется настоящим поставщиком новостей (внешнее расширение), после чего выбор —
во вкладке «Поставщики данных → Новости».

## Проверка

`python -m pytest tests/test_news_scenario.py -q` (из корня эмулятора).

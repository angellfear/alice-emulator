# Яндекс Погода — встроенный поставщик погоды эмулятора

Поставляется с эмулятором (`server_emulator/plugins/yandex-weather/`, id
`builtin.yandex-weather`), включён по умолчанию. Основным остаётся Open-Meteo (авто-выбор
берёт первый id по алфавиту); Яндекс Погода выбирается в «Поставщиках данных → Погода».

## Ключ

API Яндекс Погоды v2 работает только с ключом: кабинет разработчика Яндекса →
подключить «API Яндекс Погоды» → ключ в настройку плагина «Ключ API». Без ключа
поставщик отвечает ошибкой, сценарий погоды — честным отказом.

## Что отдаёт

`GET api.weather.yandex.ru/v2/forecast?lat&lon&lang=ru_RU&limit=2&hours=true`, ответ
приводится к форме Open-Meteo (как у `builtin.open-meteo`): `current` — из `fact`,
`hourly` — 24 часа из `forecasts[].hours` с текущего часа места, `daily` — два дня по
частям суток `parts` (мин/макс, условие дня, вероятность осадков, ветер и порывы в м/с,
направление). Условия (`condition`) переводятся в коды WMO.

Фразы погоды объявляет `builtin.open-meteo`; город («погода в Москве») переводится в
координаты геокодером Open-Meteo (`geocoding-api.open-meteo.com`).

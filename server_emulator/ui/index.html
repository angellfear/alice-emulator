Сценарии без ИИ

Простые команды (время, таймеры, будильники, свет, громкость, приложения) выполняются сценариями без обращения к модели; если сценария нет — отвечает ИИ. Определение — один файл на сценарий (state/scenarios): имя и описание ru/en, триггеры-паттерны; JSON — простой ответ, py-скрипт — логика.

Дерево: раздел → подраздел (_group пакета) → сценарии. ▸/▾ или клик по названию — свернуть/развернуть; галочка узла включает/выключает всё внутри.

Инструменты устройства и MCP

Схема инструмента передаётся модели только при enabled=true. Предложение модели не выполняется автоматически.

Пример: [{"id":"device","url":"http://127.0.0.1:9000/mcp","api_key":""}]. Поддержан JSON HTTP; SSE и stdio пока не подключены.

Расширения

Расширения добавляют сценарии, эндпоинты, конфиги Quasar, режимы «Интеллекта» и пакеты голосового стека. Источник — каталог (JSON-индекс), GitHub-репозиторий, zip-ссылка или локальная папка. Расширения с кодом (классы «код» и «установка») исполняются в процессе сервера без песочницы: устанавливайте только то, чему доверяете.

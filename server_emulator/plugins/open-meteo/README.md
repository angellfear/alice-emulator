# Open-Meteo — встроенный поставщик погоды эмулятора

Поставляется с эмулятором (`server_emulator/plugins/open-meteo/`, id `builtin.open-meteo`):
виден во вкладке «Расширения» как «Встроенные», включён по умолчанию, удалить и
обновить отдельно нельзя. Виден в «Поставщиках данных → Погода»; выбрать другого
поставщика погоды можно там же (внешнее расширение с папкой `weather/*.py`).

## Что отдаёт

Прогноз по координатам дома в форме Open-Meteo: `current` (температура, ощущается,
код погоды, день/ночь), `hourly` (лента на сутки — почасовая карточка), `daily`
(мин/макс, вероятность осадок). Кеш и свежесть — датасет `weather` (записи в БД):
сценарий погоды отвечает данными записи, при устаревании дёргает поставщика, при
сбое озвучивает старую запись с пометкой «Данные не актуальны».

## Источники

Основной — `api.open-meteo.com/v1/forecast`; URL можно заменить в настройках плагина
(Open-Meteo-совместимый ответ). Недоступен — резерв `api.met.no` (locationforecast
2.0), ответ приводится к форме Open-Meteo. Оба хоста объявлены в
`permissions.network`; эмулятор ходит на них только при обновлении записи датасета.

## Координаты

Берутся из параметров пользователя (дом): «Параметры → Значения», ключи
`user.location.latitude/longitude`. Без координат сценарий погоды отвечает
«Не знаю, где вы» — задайте дом в параметрах.

## Проверка

`python -m pytest tests/test_weather_provider.py -q` (из корня эмулятора): тесты
встроенного плагина на подменном HTTP — настоящие api.open-meteo.com и api.met.no
из автотестов не вызываются.
